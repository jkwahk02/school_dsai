## For students

Open the course's repository, then follow its setup guides:

1. **`SETUP_common.md`** — one-time setup (install Miniconda + set mirrors), reused across all courses
2. **`<COURSE>_SETUP.md`** — the short per-course note

After the one-time setup, everything runs fully offline.
